# Website Testing Report Samples

## Overview

This project demonstrates a structured format for documenting website and digital product testing observations.

## Test Report Format

### Title

Short description of the issue.

### Environment

- Device:
- Browser:
- Operating system:
- Date tested:

### Steps to Reproduce

1. Open the website or application.
2. Navigate to the relevant page.
3. Perform the required action.
4. Observe the result.

### Expected Result

Describe what should happen.

### Actual Result

Describe what happened instead.

### Severity

- Low
- Medium
- High
- Critical

### Supporting Evidence

Include screenshots, screen recordings, or other relevant evidence when permitted.

## Quality Principles

- Use clear and objective language.
- Describe one issue at a time.
- Include enough information to reproduce the issue.
- Separate observed facts from assumptions.
- Check the report before submitting it.
