# Image Annotation Guide

## Overview

This document summarizes common image annotation tasks and the purpose of each annotation type.

## Annotation Types

### Bounding Boxes

Bounding boxes are rectangular areas drawn around objects of interest. They are commonly used for object detection.

### Image Classification

Image classification assigns one or more labels to an entire image.

### Semantic Segmentation

Semantic segmentation assigns a class label to each pixel in an image.

### Keypoint Annotation

Keypoints identify important points on an object, such as joints, corners, or facial landmarks.

### Video and Temporal Labeling

Temporal labeling identifies events, objects, or actions across selected video frames or time periods.

## Quality Checks

- Follow the project guidelines.
- Use consistent labels.
- Check that objects are completely covered where required.
- Avoid unnecessary or incorrect annotations.
- Review the completed image before submission.
- Apply the same decision-making process across similar examples.
