# AI Response Evaluation Samples

## Overview

This project demonstrates a structured approach to reviewing AI-generated responses for quality, accuracy, relevance, logical consistency, and instruction-following.

## Evaluation Criteria

- Relevance to the user’s request
- Factual accuracy
- Completeness
- Logical consistency
- Clarity
- Instruction-following
- Unsupported claims or hallucinations
- Safety and appropriateness

## Sample Evaluation Format

### Prompt

Explain the difference between image classification and object detection.

### Evaluation Areas

- Is the response relevant to the prompt?
- Does it accurately explain both concepts?
- Does it distinguish between classifying an entire image and locating objects within an image?
- Does it contain unsupported or confusing claims?

### Feedback

The response should clearly explain that image classification assigns one or more labels to an image, while object detection identifies and locates individual objects using bounding boxes. Any response that confuses these tasks should be marked for revision.
